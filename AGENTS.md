# Project Details 

- This project is a telegram bot that helps to determine what is the best credit card to use given the rules of the credit card, the place that they are shopping at, and the amount paid at the certain place
- The bot also tracks the spending limits of the user, to check when the credit card limit for rewards has been reached
- It allows the user to input new MCC codes and new shops, and add and delete new locations that they shop at

# Rules

## 1. Commit Conventions
- Always use conventional commits when committing the changes. When committing, the commit must be double checked by me before it is allowed to be executed

## 2. Verification and Execution Modus Operandi
- If you are unsure of anything, pause the execution and ask me before continuing. If it is something that we have not discussed beforehand, once again pause and ask

- There should be an updated requirements.txt in the project root folder; unused modules should be raised and requested for deletion (meaning you ask me if I still use it and delete if I say so)

## 3. Tech Stack
- The project will be implemented using Python 3.13, SQLite and it is in the form of a telegram bot

## 4. Testing
- This project will experiment with test-driven development. Write tests first, and then write code to pass those tests
- The tests should be written in a tests folder in the root folder
